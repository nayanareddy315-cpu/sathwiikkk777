## ✨ Key Features & Architecture

### 1. 🤖 Embedded M.J.Ö.L.N.I.R. Chatbot (Zero-Hallucination AI)
- Fully grounded local conversational engine built with domain-specific knowledge rules.
- **Zero hallucinations**: Answers queries strictly based on verified profile records.
- Hybrid architecture: Seamlessly queries `/api/chat` when online, with an instant offline fallback engine for static deployments (GitHub Pages).

### 2. ⚡ Cinematic Marvel Universe Visual System
- Custom dynamic particle canvas (`MarvelBackground.tsx`) with floating comic energy nodes, nebula gradients, and interactive ambient glow.
- Glassmorphic translucent panels with accessible WCAG-compliant high-contrast typography.
- Smooth hardware-accelerated micro-animations.

### 3. 🎯 Full Section Breakdown
- **Hero & Identity**: Animated typewriter headline, superpower badges, and quick CTA buttons.
- **About & Core Strengths**: Educational background, growth mindset, and technical dedication.
- **Arsenal (Skills)**: Categorized skill matrix covering C, Java, DSA, Web Tech, and Developer Tools.
- **Missions (Projects)**: Detailed project cards with live demo links, repository buttons, and architecture highlights.
- **Academic & Experience**: Formal coursework and software engineering practice milestones.
- **Verified Achievements**: Round 2 Technical Qualifier credentials and achievements.
- **Coding Profiles**: One-click direct links to verified profiles on **LeetCode**, **CodeChef**, and **GitHub**.
- **Candidate Dossier**: Standardized ATS-ready resume viewer and direct download.
- **Direct Transmission**: Fully validated interactive inquiry form with real-time feedback.

## 🚀 Running Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or newer recommended)
- `npm` or `pnpm`

### Quick Start
```bash
# 1. Clone repository
git clone https://github.com/sathwikkk777/ks_files.git

# 2. Navigate to project root
cd ks_files

# 3. Install dependencies
npm install

# 4. Start development server
npm run dev
```

Open your browser at **`http://localhost:5173`** to view the application.

---

## 📦 Building for Production

```bash
# Compile TypeScript and generate optimized static bundle in dist/
npm run build

# Preview production build locally
npm run preview
```
